# imagent Documentation

imagent is a local-first image and video generation studio for individual creators. It ships as both an Electron desktop application and a command-line tool, and both interfaces share the same local workspace under `~/.imagent/` by default.

The user documentation is split by topic:

- [Quick Start](./quick-start.md) — get the CLI or desktop app running, configure a first provider, and generate your first image or video.
- [Installation](./installation.md) — install the CLI and desktop application, or build them from source.
- [Updates](./updates.md) — update the CLI, desktop application, and model catalog.
- [CLI Usage](./cli.md) — use CLI commands for generation, config, catalog, assets, gallery, and jobs.
- [Providers](./providers.md) — configure OpenAI, Azure OpenAI, Google, Flux/BFL, ByteDance, xAI, and custom OpenAI-compatible providers.
- [Configuration](./configuration.md) — understand workspace files, app preferences, secrets, environment variables, and the model catalog.
- [Best Practices](./best-practices.md) — protect secrets, back up local data, use assets and model capabilities effectively, and manage async video jobs.
